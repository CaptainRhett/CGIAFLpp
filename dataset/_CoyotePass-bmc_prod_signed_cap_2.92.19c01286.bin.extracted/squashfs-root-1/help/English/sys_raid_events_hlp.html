Events Log - Help

This page uses page navigation to display event log messages.

Events Log

The event log is composed of the following 4 materials.

    SeqNo: Event log sequence number.

    Level: Type of Event log, Information, Error ...etc.

    Event ID: Event ID of Event log.

    Time: Time when the event log was generated.

    Description: Event log detailed description.

Actions
Controller selector

Pick Controller selector for showing Events Log of different RAID Controller.

Page navigation

Press the button > to view the next page of log messages.
