NVMe Information - Help

This page displays status information for each Intel ® Corporation NVMe drive installed into a Hot Swap drive slot. Each group box displayed contains statistics for a single NVMe drive. The group box identifies the drive by Hot Swap Backplane (HSBP) number, and by drive slot number. Only five of the entries are able to change state at runtime:

NVMe Powered: Indicates the current power on state of the NVMe drive. This value can only be presented when the HSBP is powered.

NVMe Functional: Indicates the NVMe drive is reporting as operational.

NVMe Reset Required: Indicates if the NVMe drive is reporting a condition requiring the drive to be reset.

PCIe Link Active: Indicates the PCIe SERDES link is currently trained.

Drive Life Consumed: Provides information about the rough amount of wear to which the NVMe drive has been subjected. This value is NOT an absolute health indicator. This value can exceed 100% and the drive may still be considered to be healthy.
