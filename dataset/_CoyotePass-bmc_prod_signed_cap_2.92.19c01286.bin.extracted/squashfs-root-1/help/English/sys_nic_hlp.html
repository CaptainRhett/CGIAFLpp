NIC Information - Help

Use this page to collect system NIC information about the server.

PCI Class Code

The generic function of the device.

Slot Number

Physical Slot Number of the Slot Connect to the PCIe* port.

Vendor ID

Vendor Identification Number.

Device ID

Device Identification Number.

Current Speed(Mbps)

Current speed in Mbps (such as 10000 for 10 Gbps; 40000 for 40 Gbps).

PortIdx

Port Index in the system. This value matches the value exposed by BIOS in the IPMI specification’s Device Instance selector field definition for Get / Set System Boot Options IPMI command (Boot Options Parameter structure, Boot Flags parameter 5 data 5).

Media State

Media connection state:

  • 0 - Media is not connected
  • 1 - Media is connected
  • FFh - Media state is unknown

MAC Address

Network MAC address.

Firmware Version

The version of the firmware installed on the NIC.

Device Type

Physical connection type of the device.

Physical Address

Physical address of the devices based on the device type.

Other NCSI information definition

For all NCSI Information, please refer to DMTF documentation number DSP0222.
