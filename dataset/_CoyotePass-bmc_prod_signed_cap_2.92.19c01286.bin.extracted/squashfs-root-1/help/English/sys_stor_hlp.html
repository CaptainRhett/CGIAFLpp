Storage Information - Help

Use this page to collect system storage information about the server.

Port Destination

Identifies the physically labelled port or board position where the storage device is located. EXAMPLE: “SATA Port 0” or “PCIe Port 1”.

Device Index

Index of this device in the IPMI Get /Set Boot Options command as provided by BIOS. This is used by PSME to identify the boot device index for use in Set Boot Options IPMI command when a change of boot device is required.

Connector Type

Connector Type indicator:

  • 00h = Unknown
  • 01h = SATA
  • 02h = SAS
  • 03h = PCIe
  • 04h = m.2
  • 05h = USB
  • 06h = U.2

Protocol

Device Protocol indicator:

  • 00h = Unknown
  • 01h = IDE
  • 02h = AHCI
  • 03h = NVMe
  • 04h = USB

Device Type

Device Type indicator:

  • 01h = HDD
  • 02h = SSD
  • 03h = Optical - DVD
  • 04h = Optical - Blue Ray*
  • 05h = USB

Capacity(GB)

Device Capacity in GB.

RPM

Device RPM value (applicable for HDDs. 0 for Non HDD).

Model

The model string of the device.

Serial

The serial number of the device.

PCI Class Code

PCI Class code in case of PCIe storage device, 0 otherwise.

Vendor ID

PCI Vendor ID in case of PCIe storage device, 0 otherwise.

Device ID

PCI Device ID in case of PCIe storage= device, 0 otherwise.

Firmware Version

The firmware version of the device.
