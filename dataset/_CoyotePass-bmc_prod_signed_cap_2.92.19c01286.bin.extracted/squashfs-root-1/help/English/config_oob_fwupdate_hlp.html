BIOS/ME Firmware Update - Help

Use this page to upload new firmware(BIOS/ME/FD).

BIOS/ME Firmware Update

The image version information are available for viewing, as well as the option to select and upload or drag and drop a new firmware image. By dropping a new image on the page or selecting upload, web service begins its firmware update process, which will take a couple of minutes. When it is finished, it will store the image inside BMC. Perform the update server reboot (DC cycle), BIOS will mount the image as USB virtual media and the image.

BIOS Rev

Displays the current BIOS version.

Mgmt Engine (ME) FW Rev

Displays the current ME firmware version.

NOTE: When the KCS mode is deny-all, BIOS OOB firmware update is not available, please change KCS mode to restricted or allow all.

Actions
Select image type

Select image type

Choose File

Choose file to upload.

Backup

When user chooses the image type "BIOS", the Backup region option will appear. When the option is enabled, the Backup region of current BIOS will be updated together.

Password

The option will appear when "Enforce Password Mode" is Enabled in BIOS. Users should input password before uploading the image.

Upload

Upload the firmware image file.
