Controller - Help

Use this page to view controller information / actual hard disks / logical disk arrays / and provided features.

Controller Info

Showing properties of Storage Controller.

If there is a BBU unit connected, the BBU relative information will be displayed:

  • BBUPresent: BBU unit whether connected.
  • BBUName: BBU Name.
  • BBUType: BBU Type.
  • BBUStatus: BBU Status.
  • BBUTemperatureCelsius: BBU temperature (Celsius).
  • BBUVoltageMilliVolts: BBU voltage millivolts.
  • BBUCurrentMilliAmps: BBU current milliamps.
  • BBUSerialNumber: BBU serial number.
  • BBURemainingBatteryPercent: BBU remaining battery percent.

Resources

Show list of physical / logical hard drives.

    Physical Devices: Displays information about the physical hard disk connected to the control card. Click the Go button to see more related information.

    Logical Devices: Displays information about the created disk array group. You can click Go to see more information and press Del to delete the logical device.

Create Volume

Create a disk array step by step.


    In the Step 1 "Free Raid Resources" dialog box, the description of RAID 10/RAID 50/RAID 60 is as follows:

    The description of RAID 10/RAID 50/RAID 60 is the principle of the RAID level, and the operation steps of creating RAID 10/RAID 50/RAID 60 are two different concepts.

    (For example, the steps we provide to create RAID 10 are: Step 1->Select RAID 10, Step 2->Select at least 4 hard drives, Step 3->Start construction; instead of doing2 sets of RAID 0 first, then 2 groups of RAID 0 build 1 group of RAID 1.)

Actions
Create Volume

Press the Create Volume menu and a dialog will pop up to guide you through the three steps of creating a disk array. You can press Cancel at any step to leave. If there are currently no physical hard disks available for creation, the alert info dialog will show up.

    Step 1: Set RAID level and select available drive disks.

    Step 2: Set the parameter volume disk name/size/strip size/disk cache policy/access policy/initial state.

    Step 3: Confirm the parameter values of the disk array to be created. If you want to modify, press the back button to modify the parameters.

Go-Physical Devices

Click the Go button, the web page will switch to the Physical Devices page, displaying the complete information of the hard drive.

Go-Logical Devices

Click the Go button, the web page will switch to the Logical Devices page, displaying the complete information of this RAID drive.

Del-Logical Devices

Click the Del button, will delete this RAID drive.
