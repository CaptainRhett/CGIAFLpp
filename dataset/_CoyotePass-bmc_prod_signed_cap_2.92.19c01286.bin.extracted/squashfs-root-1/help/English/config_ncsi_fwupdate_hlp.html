NCSI Firmware Update - Help

Use this page to upload new NCSI firmware.

NCSI Firmware Update

The image version information are available for viewing, as well as the option to select and upload or drag and drop a new firmware image. By dropping a new image on the page or selecting upload, web service begins its firmware update process, which will take a couple of minutes.

NCSI Rev

Displays the current NCSI version.
