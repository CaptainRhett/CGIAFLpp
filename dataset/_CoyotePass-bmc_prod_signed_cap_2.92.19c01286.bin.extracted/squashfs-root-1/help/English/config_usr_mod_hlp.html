Modify User - Help

Use this page to modify a user's password and permissions.

User Name

The name of the user being configured.

The name is a string of 1 to 16 alpha-numeric characters or '.','_' or '-'.

The name must begin with an alpha-numeric character or '_'.

Change Password

To change the user's password, check this box which will enable the password fields.

Password, Confirm Password

System has simple password mode and complex password mode.

Users can change system password mode in "Security Settings" page.

Enter and confirm the new password here.

  • Simple password criteria:
    • The password must be between 6 and 20 characters long.
  • Complex password criteria:
    • 1.The password length must be between 8 to 20 characters.
    • 2.The password must contain at least a space or one of the following special characters.
      • !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~
    • 3.The password must conatain below 3 types of the following characters.
      • at least one uppercase letter(A to Z)
      • at least one lowercase letter(a to z)
      • at least one digits(0 to 9)
    • The password cannot be the same as the username or username in reverse order.
    • The password must have at least two new characters when compared with previous password.

Network Privilege

The level of network privilege to assign to this user.

  • - Administrator
  • - Operator
  • - User
  • - No Access

Enable Access

Check this box to enable the user for LAN access. Also enables/disables SOL, KVM, Media Redirection.

SNMPv3 Access

Enable/Disable for SNMPv3 accessible.

SNMPv3 Access Level

The Access Level for SNMPv3.

  • - Read-Only
  • - Read-Write

SNMPv3 Authentication Protocol

The Authentication Protocol for SNMPv3.

  • - MD5
  • - SHA

SNMPv3 Authentication Passphrase

Follow the rule to set the passphrase using in authentication protocol for SNMPv3.

  • The passphrase's length needs to be set between 8 and 12.
  • If SNMPv3 authentication Protocol or the SNMPv3 privacy Protocol/Passphrase had been changed, the authentication passphrase must be set again for security demand.

SNMPv3 Privacy Protocol

The Privacy Protocol for SNMPv3.

  • - AES

SNMPv3 Privacy Passphrase

Follow the rule to set the passphrase using in privacy protocol for SNMPv3.

  • The passphrase's length needs to be set between 8 and 12.
  • If SNMPv3 authentication Protocol/Passphrase or SNMPv3 privacy Protocol had been changed, the privacy passphrase must be set again for security demand.
