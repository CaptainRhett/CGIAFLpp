KCS策略控制模式

KCS策略控制模式允许管理员管控KCS接口访问BMC。KCS接口是服务器主机（UEFI，操作系统）与BMC之间的一种通信通道。虽然KCS接口被Ring 0 访问方案保护，但是它是不可靠的，并且对于实际部署是不安全的。在BIOS启动完成后， KCS策略控制模式限制了通过KCS接口发送IPMI所定义的命令。由以下几种模式组成：

  • KCS策略控制模式 -- 全部允许

    • 此模式适用于主机操作系统和BMC之间正常的IPMI通信，在部署配置BMC时，应使用此模式。

  • KCS策略控制模式 -- 全部禁止

    • 此模式禁止从主机操作系统通过KCS接口向BMC发送命令。这是一种不兼容IPMI协议的配置，会影响主机操作系统上运行的服务器管理软件的运行。这种模式仅限于通过KCS向BMC发送IPMI命令，不影响通过网络访问BMC。

  • KCS策略控制模式 -- 限制模式

    • 此模式允许BMC固件使用访问控制列表控制权限，允许在主机操作系统上执行的应用程序可使用列表里有限的IPMI命令通过KCS接口与BMC通信。这是一种不兼容IPMI协议的配置，可能会影响主机操作系统上的服务器管理软件的运行。例如一些用于部署配置BMC的IPMI命令或者控制主机状态的命令，这些命令在这种模式下已被禁止。这种模式仅限于通过KCS向BMC发送的IPMI命令，不影响通过网络访问BMC。

在用户登录被阻挡之前，配置用户登录尝试次数。以及在用户被阻挡之后，配置用户再次登录的时间。

SSL 密码策略控制模式

SSL 密码控制模式允许管理员获取或设置系统 SSL 密码模式。选择：

  • SSL 密码策略控制模式 - 进阶

    • 此配置设置适用于“进阶”密码模式。 首次启动系统时，“进阶”是默认模式。

  • SSL 密码策略控制模式 - 广泛的兼容性

    • 此配置设置适用于“广泛兼容性”密码模式。

  • SSL 密码策略控制模式 - 最广泛的兼容性

    • 此配置设置适用于“最广泛兼容性”密码模式。

  • SSL 密码策略控制模式 - 传统

    • 此配置设置适用于“传统”密码模式。

尝试登录

尝试登录失败次数

输入尝试登录失败的时间区间。 设定用户在被锁定之前的尝试登录的次数。0表示不锁定。尝试登录失败次数在0-255之间。默认值是3次。

用户锁定时间（秒）

设置已经被锁定的用户被允许再次登录进来的时间。 0表示用户锁定时间未启用。 如果用户由于使用错误的密码值而被禁用，那么直到使用设置用户存取命令来重新被启用之前用户都要保持禁用状态。 用户锁定时间应该在0-65535之间。默认值是60秒。

端口设定

HTTPS 安全端口

为https(默认:443)的 web会话设置端口。 修改这个设置会立即中断当前所有web会话。

密码规则

复杂度

密码规则的功能是避免出于安全考虑而设置不太复杂的密码。

密码验证在不同模式下是不同的严格要求

  • 中

    • * 仅包含可打印字符

    * 密码长度不应短于8个字符

    * 不能包含用户名或相反用户名。（不区分大小写）（例如，username = Hello，Password = th12（oLLeh）_78也不允许）

    * 与以前的密码相比，至少要有两个新字符。

    * 符合以下4个条件：

    1. 包含大写

    2. 包含小写

    3. 包含数字

    4. 至少包含一个空格或符号

  • 低

    • * 仅包含可打印字符

    * 密码长度不应短于6个字符

    * 符合以下3个条件：

    1. 包含大写

    2. 包含小写

    3. 包含数字

    4. 至少包含一个空格或符号

    * 不能包含用户名（不区分大小写）（例如，username = Hello，Password = th12（heLLo）_78不允许）

  • 高

    * 仅包含可打印字符

    * 密码长度不应短于8个字符

    * 符合以下4个条件：

    1. 包含大写

    2. 包含小写

    3. 包含数字

    4. 至少包含一个空格或符号

    * 不能包含用户名或相反用户名。（不区分大小写）

    * 不能包含超过或等于3个字符的连续数字（例如，不允许使用BMC（123）ste，BMC（654）sfc）

    * 不能包含超过或等于3个字符的连续字母（例如（AbC）3478 !，不允许使用57 $（DeF）68k））

    * 字母不能超过3个字符（例如（Fher）145！不允许）

    * 数字不能超过3个字符（例如，不允许Fgke（1245）＃@，（4390）FGL $）

    * 连续符号不能超过3个相同的字母（不区分大小写）（例如Fkr4fcpF, f（4个“ f”或“ F”），Glg5gt2G！（4个“ g”或“ G”））

密码记录

密码历史记录的功能是避免设置与我们先前出于安全考虑使用的密码重复的密码。

例如，当历史记录设置为2时，表示用户无法设置为同一帐户配置的前两个密码中使用的新密码。
