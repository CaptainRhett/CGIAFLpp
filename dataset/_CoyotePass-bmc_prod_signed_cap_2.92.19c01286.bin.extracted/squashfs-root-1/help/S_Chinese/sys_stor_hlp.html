存储信息 — 帮助

使用此页面来收集服务器上安装的存储的信息。

目的地端口

标识存储设备所在的带有物理标签的端口或板的位置。示例：“ SATA端口0”或“ PCIe端口1”。

设备索引

BIOS提供的IPMI Get / Set Boot Options命令中此设备的索引。当需要更改启动设备时，PSME使用它来标识要在“设置启动选项” IPMI命令中使用的启动设备索引。

连接器类型

连接器类型指示灯：

  • 00h = 未知
  • 01h = SATA
  • 02h = SAS
  • 03h = PCIe
  • 04h = m.2
  • 05h = USB
  • 06h = U.2

协议

设备协议指示灯：

  • 00h = 未知
  • 01h = IDE
  • 02h = AHCI
  • 03h = NVMe
  • 04h = USB

设备类型

设备类型指示灯：

  • 01h = HDD
  • 02h = SSD
  • 03h = Optical - DVD
  • 04h = Optical - Blue Ray*
  • 05h = USB

容量（GB）

设备容量（GB）

RPM

设备RPM值（适用于HDD。0适用于非HDD）

型号

设备的型号字符串。

序列号

设备的序列号。

PCI类型代码

如果是PCIe存储设备，显示PCI类型代码，否则为0。

供应商编号

如果是PCIe存储设备，显示PCI供应商识别码，否则为0。

设备编号

如果是PCIe存储设备，显示PCI设备识别码，否则为0。

固件版本

设备的固件版本。
