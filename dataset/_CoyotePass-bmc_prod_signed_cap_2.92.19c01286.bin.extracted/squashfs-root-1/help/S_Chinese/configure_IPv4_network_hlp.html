IPv4 网络 — 帮助

使用此页面为服务器管理配置网络设置。

主机名称

主机名称是一个符合RFC 1123, 少于64个字母数字字符的字符串。主机名称可以包括连字符但不能是第一个或者最后一个字符。默认值为BMC+MAC地址 (範例: MAC地址'00 1e 67 f9 2f b3'，预设主机名称会是'BMC001E67F92FB3')。 (注意：如果OCP卡没有被识别，预设主机名会是'BMC000000000000'。在这种情况下，这个主机名会在OCP卡被识别，并重新加载页面后，更新为BMC+MAC地址)

启用故障转移

启用故障转移绑定所有可用的以太网接口到第一个局域网频道。当主接口绑定断开的话，二级接口会以相同的IP地址被自动激活

选择要绑定的以太网设备。

选择指定网络通道到主网络通道。

启用Host Interface

Host Interface基于USB以太网。 它提供了主机和BMC之间的通信接口，该接口实现了许多功能，包括iKVM（HID鼠标和键盘）和虚拟媒体。

如果尚未启用Host Interface，则必须启用并保存。 然后继续设置主机接口配置。

Host Interface仅支持静态IP，并且只能修改IP地址和网络掩码。

局域网通道

它列出了可用于管理服务器的局域网通道。

MAC地址

设备的MAC地址(只读)。

网络接口控制器

显示局域网通道的网络接口控制器是专用于BMC/主机或是主机和BMC共用（只读）。

网络链接

显示局域网通道的网络链接状态（只读）。

IP地址

使用单选按钮来选择IP分配的类型。 如果配置一个静态IP,在给定的字段输入所请求的IP地址、子网掩码、网关、主DNS和二级DNS服务器。

  • - IP地址是由4个数字用点隔开如“xxx.xxx.xxx.xxx”。
  • - “xxx”范围从0到255
  • - 第一个“xxx”不能是0
操作
保存

点击“保存”按钮保存任何修改。

备注: 在尝试修改网络设置前，请关闭所有打开的远程控制台重定向会话。否则所有的会话将丢失。
