关
LDAP — 帮助

选择或者不选"LDAP认证"选项来启用或禁用LDAP。

LDAP认证

选择这个选项来启用LDAP认证，然后输入需要的信息来存取LDAP服务器。

通过SSL来对LDAP认证

选中该复选框通过启用LDAP SSL身份认证。

端口

指定LDAP端口。

IP地址

LDAP服务器的IP地址。

  • - IP地址是由4个数字用点隔开如“xxx.xxx.xxx.xxx”。
  • - “xxx”范围从0到255
  • - 第一个“xxx”不能是0

绑定的密码

为LDAP服务器认证密码,密码长度必须大于4个字符。

绑定的DN

LDAP服务器的专有名称，比如 "cn=Manager, dc=my-domain, dc=com".

搜索基址

LDAP的搜索基址，比如 "dc=my-domain, dc=com".

配置LDAP用户组 - 帮助

配置LDAP搜索过滤器来关联BMC网络用户权限。例如："(&(cn=BMCAdminGroup)(memberUid=%s))".

Admin 角色过滤

LDAP对应于Admin权限的搜索过滤器。

Operator 角色过滤

LDAP对应于Operator权限的搜索过滤器。

User 角色过滤

LDAP对应于User权限的搜索过滤器。

保存
